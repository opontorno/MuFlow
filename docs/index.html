Method

Figure 2. Overview of the µFlow pipeline. The backbone extracts multi-scale features from the input image and from pre-computed average images. A normalizing flow models the real-image distribution; anomaly score is the negative log-likelihood.

Feature extraction. µFlow builds on a frozen backbone (CNN or ViT) to extract multi-scale feature maps. Average images computed from the training real set are used as stable reference representations.

Normalizing flows. FastFlow coupling layers learn a bijective mapping from the feature space to a Gaussian latent space. The anomaly score for a test image is its negative log-likelihood under this learned distribution.

GMM prior. Gaussian Mixture Models fitted on pooled real features provide class-conditional priors that improve calibration and generalisation to unseen generators.
